Lesson 1. 網站是如何在手機上出現的？

💡 核心技術科普觀念

當使用者在瀏覽器輸入網址或點擊連結時，手機會向遠端伺服器發送一個 HTTP 請求。伺服器接收到後進行邏輯運作，並回傳包含網頁內容的 HTML、CSS 與 JavaScript 檔案，最後瀏覽器將其渲染成我們看見的精美網頁。這趟數據往返的實體傳輸物理距離與伺服器處理速度，就是決定網站快慢的關鍵因素。

💥 客戶痛點與常見危機

當主機單獨面對全球使用者的連線，伺服器的網路頻寬與 CPU 運算資源很容易在尖峰時刻被瞬間吃光，導致網站開啟極慢、甚至直接宕機，造成高達 40% 的使用者因載入超過 3 秒而直接流失。

🛡️ 騰雲架構優勢與話術利基

騰雲運算在全球最前線佈建了高效能的邊緣緩存網絡，大幅縮短了數據傳輸的實體物理距離。請求不再需要每次都大老遠跑回客戶源站，從源頭解決了網頁連線延遲的問題。

Lesson 2. 什麼是 DNS？網路世界的導航員

💡 核心技術科普觀念

DNS（Domain Name System，網域系統）就像是網路世界的『電話簿』。電腦底層只認識由數字組成的 IP 位址（例如 211.23.85.12），而人類只記得住網址（例如 www.skycloud.com.tw）。DNS 的任務就是將人類輸入的網址，精準翻譯成電腦看得懂的實體 IP 數字。

💥 客戶痛點與常見危機

如果客戶的網域解析速度過慢，使用者在輸入網址後會卡在白畫面數秒；更嚴重的是，若傳統的 DNS 伺服器遭受攻擊癱瘓，全世界的客人就都無法找到路，網站即便沒掛也如同蒸發一樣。

🛡️ 騰雲架構優勢與話術利基

我們提供高可用性、全球分佈式的頂級 DNS 解析服務。藉由高效能解析架構，將網域尋路時間縮短至毫秒級別，確保全球任何地區的客人都查得到路、進得來店面。

Lesson 3. 為什麼 DNSSEC 是企業生意的安全保險？

💡 核心技術科普觀念

DNS 查詢預設是沒有加密且容易被偽造的。DNSSEC（網域系統安全擴充）透過在 DNS 解析層級引入『數位簽章』技術。當瀏覽器向 DNS 伺服器索取 IP 時，會同時驗證數位簽章是否正確，從底層杜絕駭客在傳輸途中偽造或竄改解析紀錄。

💥 客戶痛點與常見危機

若沒有 DNSSEC 防護，駭客可利用『DNS 劫持』漏洞將您的忠實客戶導向一個長得一模一樣的偽造釣魚網站，騙取會員密碼與信用卡號。企業將在一夜之間喪失客戶信任與面臨巨額法律訴訟。

🛡️ 騰雲架構優勢與話術利基

騰雲運算的平台全面原生支援頂級 DNSSEC 安全簽章機制，配合獨家研發的優化快取演算法，達成『最高安全規格』與『極致解析速度』的完美共存。

Lesson 5. 什麼是 CDN？全球邊緣快取網路

💡 核心技術科普觀念

CDN（Content Delivery Network）是一種透過在全世界部署數百、數千台快取伺服器（節點）所組成的分佈式網路系統。它的核心邏輯是：把客戶網站上的靜態檔案（如商品圖片、影片、活動海報、樣式檔）複製一份，提前發送到離使用者最近的邊緣節點上，實現地緣上的就近存取。

💥 客戶痛點與常見危機

如果企業的原始主機在台北，美國或東南亞的客戶要下載產品圖片時，數據必須橫跨太平洋，連線速度極慢；若遇到熱門搶購檔期，數萬人同時向單一主機要資料，會直接把主機頻寬撐爆而癱瘓。

🛡️ 騰雲架構優勢與話術利基

騰雲運算擁有全球深度佈建的頂級 CDN 邊緣網路。我們能將客戶的產品內容瞬間推播到離世界各國消費者最近的前線節點，實現全網秒開的完美流暢體驗。

Lesson 6. 靜態快取 vs. 動態加速的雙軌並進

💡 核心技術科普觀念

CDN 的加速手段分為兩種。第一種是『靜態快取』，針對圖片、CSS、JS、HTML等不會變動的內容，直接在邊緣節點落地儲存、重複利用；第二種是『動態加速』，針對購物車結帳、API數據、個人化資料等無法快取的內容，CDN 透過優化骨幹網絡與智慧路由，以走『數據高鐵專線』的方式用最快速度傳回中央源站處理。

💥 客戶痛點與常見危機

電商平台在限時搶購時，常發生商品靜態大圖跑不出來、而動態的購物車點擊結帳按鈕後因為路由塞車遲遲沒有回應，導致訂單大量結帳失敗、客戶憤而離開。

🛡️ 騰雲架構優勢與話術利基

Lesson 7. 節點 (Edge) 與回源 (Origin) 之間的微妙關係

💡 核心技術科普觀念

在 CDN 架構中，站在最前線服務客戶的快取主機被稱為『邊緣節點（Edge）』，而客戶的自有中央伺服器則被稱為『源站（Origin）』。當 Edge 節點沒有該檔案的快取時，它必須向 Origin 源站要一份過來，這個動作稱為『回源（Origin Fetch）』。如果源站當機、或者源站反應太慢導致 Edge 等不到回應，前端就會跳出 502 Bad Gateway 或 504 Gateway Timeout 的經典錯誤碼。

💥 客戶痛點與常見危機

許多缺乏調校經驗的 CDN 設定，在活動開跑、海量使用者湧入的黃金第一秒時，因為快取命中率不佳，導致所有請求同步衝回源站（稱為快取雪崩），直接把客戶源站主機壓垮，網站全面癱瘓。

🛡️ 騰雲架構優勢與話術利基

騰雲運算的專業技術工程師（FAE）具備深厚的架構調校實戰經驗。能為客戶精準設定快取過期策略與回源控制，幫客戶擋下前線 95% 以上的敲門流量，完美保護後方源站安全。

Lesson 8. 關鍵效能指標：Cache Hit Ratio 與 Latency

💡 核心技術科普觀念

評估一個 CDN 系統到底有沒有發揮實質商業功效，有兩個絕對性的核心指標：一、快取命中率（Cache Hit Ratio）：前線節點不回源、直接回傳檔案給用戶的比例，理想狀態在 85% ~ 95% 以上。二、延遲時間（Latency）：數據從發出到收到回應的往返時間（TTFB）。這兩個指標直接決定了使用者的購物流暢度與源站的頻寬節省量。

💥 客戶痛點與常見危機

很多企業買了缺乏售後優化服務的標準化 CDN，因為沒有技術團隊協助配置，快取命中率只有 20%，結果既要付 CDN 頻寬費、又要付源站爆量頻寬費，形同花兩次冤枉錢。

🛡️ 騰雲架構優勢與話術利基

我們提供秒級更新的『報告大本營』與視覺化圖表分析系統。業務能直接拿著真實數據向客戶證明：騰雲幫他們實現了超高命中率與極致低延遲，確實省下了高達九成的主機頻寬費。

Lesson 10. 站點 (Site) 與節點 (Node) 的多對多彈性宇宙

💡 核心技術科普觀念

在騰雲的系統架構中，『站點（Site）』代表客戶所管理的網站配置與網域名稱，而『節點（Node）』代表分散在全球各地的 Nginx 反向代理主機。在系統關聯上，我們支援極具彈性的『多對多自由關聯架構』。多個節點可以共同為同一個站點提供服務，而一個節點同時也可以掛載多個站點。這種設計賦予了我們在面臨大流量衝擊時，隨時動態抽調、重組硬體資源的實力。

Lesson 14. 網站應用程式專屬守衛：WAF 深度過濾

💡 核心技術科普觀念

WAF（Web Application Firewall，網頁應用程式防火牆）是專門防禦 HTTP/HTTPS 網頁層級（網路第七層）的高級守衛。傳統防火牆只檢查連線 IP 是誰、有沒有允許通過，但完全看不懂網頁語法內容。而 WAF 就像是精通語言的安檢官，能深度檢查 HTTP 請求內容裡有沒有藏著 SQL 注入（惡意偷拔資料庫）或 XSS 跨網站指令碼（植入木馬）等代碼攻擊漏洞。

💥 客戶痛點與常見危機

即使網站買了傳統防火牆，駭客只要偽裝成正常瀏覽用戶，在網站搜尋框或登入欄位輸入惡意資料庫語法（SQL 注入），就能在一秒內把客戶後台的幾十萬筆會員個資、信用卡號全部打包外洩，引發災難性商譽危機。

🛡️ 騰雲架構優勢與話術利基

我們在專屬的 Nginx 邊緣節點上直接深度整合了高效能的 WAF 規則過濾引擎。在最外圍、最前線就將所有試圖鑽網頁代碼漏洞的惡意請求直接阻斷，全面保護後台應用程式與資料庫安全。

Lesson 16. 網頁前端防護機制：點擊劫持與安全標頭配置

💡 核心技術科普觀念

『點擊劫持（Clickjacking）』是一種極具欺騙性的前端網頁駭客攻擊。駭客會利用 CSS 將客戶的正牌網站包在一個完全透明的 iframe 框架裡，並疊加在一個看似無害的惡意按鈕上方。使用者以為自己點的是免費遊戲，實際上卻是點擊了正牌網站內部的確認扣款。防禦這種攻擊的最佳手段，就是在 Nginx 伺服器回傳網頁時，強制加上 X-Frame-Options 安全標頭，嚴格限制網頁不可以被其他人任意內嵌。

💥 客戶痛點與常見危機

客戶的網站原始碼雖然寫得很安全，但因為缺乏伺服器端的前端防護安全標頭配置，被詐騙集團拿去套殼做成點擊劫持陷阱，消費者受騙上當後怪罪並起訴正牌企業，商譽重創。
